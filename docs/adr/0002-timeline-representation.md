# ADR 0002: Separate source time from output frames

Original и Master timelines хранят целые микросекунды, а Output timeline хранит целые кадры с рациональным FPS. Такое разделение не смешивает неточные timestamps анализа с дискретным timeline Remotion, исключает накопление ошибок `double` и требует явного сопоставления каждого выходного клипа с интервалами Original и Master; более простая модель «миллисекунды везде» отклонена из-за неизбежных скрытых правил округления.
